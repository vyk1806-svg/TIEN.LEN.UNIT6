# Tiến Lên Từ Vựng – Lớp 12, Unit 6 (Artificial intelligence)

Game ôn từ vựng thi đua theo đội, lấy cảm hứng từ bàn đánh bài tiến lên. Toàn bộ game nằm trong một file `index.html`, không cần cài đặt gì.

## Nội dung
- 1 lá mẫu (không tính điểm) + 28 lá bài + 5 câu follow-up, phủ đủ 31 từ Unit 6.
- 4 gợi ý mỗi lá: ♠ định nghĩa tiếng Anh · ♥ nghĩa tiếng Việt · ♦ phiên âm IPA · ♣ chữ cái đầu.
- 2–4 đội (Bích ♠, Cơ ♥, Rô ♦, Chuồn ♣), chặn bài, đánh tiếp, bục xếp hạng.
- Mặc định: lượt 30 giây, cướp 15 giây, follow-up 20 giây (đổi được ở màn hình thiết lập).

## Cách dùng
- Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.
- Phím tắt: 1–4 lật gợi ý · Enter = Đúng · X = Sai · P = tạm dừng · N = tiếp tục. Khi đang gõ chữ: Enter = Kiểm tra, Esc = thoát ô gõ.
- Ván đang chơi được lưu trong trình duyệt của máy đang dùng.

## Ghi chú
- Nghĩa và loại từ lấy theo bảng từ của giáo viên. Phiên âm IPA được bổ sung theo giọng Anh–Anh.
